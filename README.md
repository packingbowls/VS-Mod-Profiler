A portable, lightweight, and standalone executable that organizes your Vintage Story mods into selectable and loadable profiles. No bloat or convoluted GUI contained, for those who want something STRAIGHT to the point. This is the smallest alternative to VS-Launcher, a Vintage Story launcher that somewhat mirrors Modrinth.

This program is a CLI tool that organizes your Vintage Story mods across separate profiles for each version with full customization. You can place mods you want enabled across all profiles for specific versions in the /versionname/Persist/ directory to save disk space. You can name your versions and profiles anything valid, but it's recommended to name them by VS version.

Upon first run, the program needs to create new directories in your /VintagestoryData/ folder. You can access these from inside the program or via explorer.
Be sure to run the app as administrator. It relies on *symlinks*, something only programs with admin permissions can create/modify.
